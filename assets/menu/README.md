# Menu assets

Place optional main menu assets in this folder.

- Background: `background.png`, `background.jpg`, `background.jpeg`, `background.bmp`, `background.webp`, `menu_background.*`, or `main_menu_background.*`
- Music: `music.ogg`, `music.mp3`, or `music.wav`
- Snow particle: `snow.png`

If this folder has no image, the game draws a procedural animated background.
If this folder has no music, the menu tries to loop the first audio file found in `songs/`.
The snow effect uses `snow.png`; if it is missing, the snow effect is disabled.
